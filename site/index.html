TurboWarp Voice Chat

Talk with an AI by voice in a TurboWarp project. Choose how your voice is heard and how replies are spoken, let the AI call your block functions, and take forced coffee breaks to keep sessions short and cheap.

Before you start

  1. Start @kubohiroya/capability-proxy on 127.0.0.1 with the openai provider. Note the eight-digit pairing code.
  2. Load turbowarp-voice-chat.js as a custom extension with Run without sandbox enabled.

Good to know

  • After a coffee break the AI starts fresh and does not remember the earlier talk.
  • Pressing the stop button ends the conversation.
  • AI usage [costUSD] is an estimate; check the OpenAI dashboard for real charges.
  • If something fails, check last voice chat error.

Repository guide and examples

Fixed input editing

With a compatible TurboWarp GUI, enable fixed-input forms to edit only standard literal fields. Numbers use complete finite JSON number tokens; menu fields use existing choices. Connected reporters and unavailable fields stay read-only and are never evaluated. Saving an unchanged form preserves exact existing raw values, including legacy spellings and unknown choices. Invalid drafts stay in the same editing session; cancel, project/target replacement, or block removal discards them. Disabling the GUI feature flag restores native field editing. This form does not run blocks, open network/audio/key/QR sessions, resolve names, or edit Schema arguments. Coffee-break minutes must be nonnegative and remain finite after multiplication by 60.

  • setSpeechInput: INPUT
  • setSpeechOutput: OUTPUT
  • setAllowInterruptions: ONOFF
  • setCoffeeBreak: TALK, BREAK, AFTER
  • defineFunction: EXPORT
  • usageValue: FIELD
